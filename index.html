⚙️ Réglages

Gratuite sur aistudio.google.com/apikey — sert aussi pour la voix Gemini et les images.

gemini-flash-latest = toujours le Flash le plus récent. Si le modèle est surchargé, l'app en essaie un autre automatiquement.

ElevenLabs

Sur elevenlabs.io → API Keys. Active les permissions « Text to Speech », « Voices (read) » et « User (read) » (pour voir les crédits restants).

—
🍁 Voix québécoise Microsoft (gratuite)

Les voix d'ici de la lecture à voix haute de Microsoft Edge, par le relais de ton serveur : gratuites, sans compte et sans limite. C'est un service non officiel : s'il cesse de répondre, l'app passe toute seule à la voix suivante. Elle lit sans les chuchotements ni les rires.

🍁 Voix québécoise Google (Cloud Text-to-Speech)

Activer l'API : Cloud Text-to-Speech · créer la clé : Identifiants → Clé API (restreinte au site de l'app et à « Cloud Text-to-Speech API »).

—

Gratuit chaque mois jusqu'au quota de Google (environ 1 million de caractères pour les voix haut de gamme). L'app s'arrête d'elle-même au plafond ci-dessus pour ne jamais rien te coûter. Les voix « Chirp3-HD » sont les plus naturelles.

Voix Gemini (gratuite)

Gratuite avec ta clé Gemini, mais limitée en nombre d'appels par minute : une histoire peut prendre une minute ou deux à enregistrer.

Voix du téléphone

Les voix « Français (Canada) » donnent l'accent d'ici. Pour en ajouter : Paramètres du téléphone → Synthèse vocale → Google → Installer les données vocales.

Pendant l'histoire

L'image demande un modèle d'images Gemini : avec certaines clés gratuites, elle n'est pas disponible (l'histoire se crée quand même).

☁️ Sauvegarde Google Drive

Rangées dans Drive → « Histoires du soir » → un dossier par enfant → un dossier par histoire (Google Doc + audio + image). Les favoris ont aussi un raccourci dans « ⭐ Favoris ». Le plus simple : touche le lien du document « ⚙️ Configurer l'app » dans ce dossier, il remplit tout.

📲 Version de ton serveur

L'app est aussi sur ton serveur : 95.groupelaberge.ca/histoires (bouton « Histoires » de l'app Maison). Ce bouton y copie tes clés et tes réglages, puis récupère tes histoires depuis le Drive.
